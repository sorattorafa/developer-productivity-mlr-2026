## Resumo

Este artigo da InfoQ reporta o lançamento do framework **DX Core 4**, desenvolvido pela organização DX para a medição da produtividade de desenvolvedores [1]. O framework é apresentado como uma estrutura unificada que encapsula modelos anteriores bem conhecidos na indústria [1].

A estrutura do **DX Core 4** é organizada em quatro dimensões principais: **speed**, **effectiveness**, **quality**, e **business impact** [1]. O objetivo central do framework é integrar as métricas de **DORA**, **SPACE**, e **DevEx** em um modelo único e coeso [1].

---

## Frameworks Mencionados

*   **DX Core 4**: Discutido como o novo framework unificado lançado para medir produtividade [1].
*   **DORA**: Mencionado como um dos modelos encapsulados pelo DX Core 4 [1].
*   **SPACE**: Mencionado como um dos modelos encapsulados pelo DX Core 4 [1].
*   **DevEx**: Mencionado como um dos modelos encapsulados pelo DX Core 4 [1].

## Metricas Mencionadas

*   **Speed**: Uma das quatro dimensões principais para medir o desempenho do desenvolvedor [1].
*   **Effectiveness**: Uma das quatro dimensões principais focada na eficácia do trabalho [1].
*   **Quality**: Uma das quatro dimensões principais voltada para a qualidade técnica [1].
*   **Business Impact**: Uma das quatro dimensões principais para medir o valor gerado para o negócio [1].

---

## Insights para Praticantes

*   A adoção de um framework unificado permite consolidar métricas de diferentes fontes (como as métricas operacionais do **DORA** e as métricas de bem-estar do **SPACE**) em uma visão holística [1].
*   A medição da produtividade deve abranger dimensões variadas, incluindo o impacto direto no negócio (**business impact**) e a eficácia (**effectiveness**), indo além de métricas simples de velocidade [1].
