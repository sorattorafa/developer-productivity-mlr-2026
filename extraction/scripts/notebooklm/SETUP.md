# NotebookLM Processor: Setup and Usage Guide

## 1. Installation

```bash
# Install the library (requires Python >= 3.10)
pip install "notebooklm-py[browser]" openpyxl

# Install the browser used for authentication
playwright install chromium
```

## 2. Authentication

```bash
# Log in through the browser (opens Chrome; sign in to Google)
notebooklm login
```

This stores the credentials locally. It only needs to be done once.

## 3. Usage

### Show the current status
```bash
python process_papers.py --mode status
```

### Dry run (show what would be processed, without running it)
```bash
python process_papers.py --mode extract --dry-run
```

### Process a stratified sample (recommended first)
```bash
# Build a sample of 25 papers stratified by period
python process_papers.py --mode sample --sample-size 25 --dry-run

# Run the sample
python process_papers.py --mode sample --sample-size 25
```

### Process all papers (in batches of 10)
```bash
python process_papers.py --mode extract --batch-size 10
```

### Process by source
```bash
python process_papers.py --mode extract --source IEEE --batch-size 10
python process_papers.py --mode extract --source ACM --batch-size 10
python process_papers.py --mode extract --source Google_Scholar --batch-size 10
python process_papers.py --mode extract --only-gl --batch-size 10
```

### Resume where it stopped
```bash
# The script saves its progress automatically in progress.json
python process_papers.py --mode extract --batch-size 10
```

### Resume from a specific paper
```bash
python process_papers.py --mode extract --start-from P0030
```

### Reprocess papers that failed
```bash
python process_papers.py --mode retry --batch-size 5
```

### Adjust the delay between papers (default: 30 s)
```bash
python process_papers.py --mode extract --delay 45
```

### Search update of October 2026
```bash
# same prompts and output format; reads the list in update_2026-10_papers.json
python process_update.py --mode status
python process_update.py --mode extract --batch-size 10
```

## 4. Comparing Claude and NotebookLM

After processing the papers, use the merge script:

```bash
# Agreement statistics
python merge_summaries.py --stats

# Full report
python merge_summaries.py --report

# Divergences only
python merge_summaries.py --divergences

# Merged summaries (Claude as base + notes on divergences)
python merge_summaries.py --merge
```

The comparison of the October 2026 update is produced by `extraction/scripts/compare_update_2026-10.py`.

## 5. File structure

```
extraction/scripts/notebooklm/
  process_papers.py       # main processing script
  process_update.py       # runs the same prompt on the sources of the October 2026 update
  merge_summaries.py      # comparison and merge script
  SETUP.md                # this guide
  progress.json           # progress, saved automatically (created on the first run)
  sample_list.json        # sample list (after --mode sample --dry-run)
  output/                 # summaries generated by NotebookLM
  merged/                 # merged summaries (after --merge)
```

The NotebookLM outputs used in the review are in `extraction/notebooklm/`.

## 6. Notes

- **Rate limits**: NotebookLM has undocumented limits. The script waits 30 s between papers and 120 s every 10 papers.
- **Gray literature**: many sources are .txt files, not .pdf. NotebookLM also accepts text.
- **Usage limits**: NotebookLM has usage limits per Google account.
- **Progress**: if the script is interrupted, run it again and it continues where it stopped.
