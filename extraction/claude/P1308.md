# Rethinking Productivity in Software Engineering

## Dados Bibliográficos
- **Autores**: Caitlin Sadowski, Thomas Zimmermann (Editors)
- **Ano**: 2019
- **Venue**: Apress Open (Book)
- **DOI**: https://doi.org/10.1007/978-1-4842-4221-6
- **Fonte**: Google Scholar
- **Paper ID**: P1308

## Objetivo
Livro editado que oferece perspectiva abrangente e crítica sobre produtividade em engenharia de software, desafiando conceitos tradicionais. Compila 13+ capítulos cobrindo: definições de produtividade, métricas técnicas e comportamentais, fatores que influenciam produtividade (técnicos, organizacionais, comportamentais), impacto de interrupções, felicidade de desenvolvedores, e metodologias ágeis. Apresenta framework multidimensional considerando indivíduo, equipe, organização e mercado para avaliação equilibrada de produtividade.

## Métricas e Instrumentos de Avaliação
- **Frameworks mencionados**: Software Development Productivity Framework, Velocity, Quality, Satisfaction Lenses, Knowledge Work perspective, Individual/Team/Organization/Market Four Lenses
- **Métricas mencionadas**: Code metrics (size, complexity, defects), Effort metrics, Velocity, Cycle time, Lead time, Quality conformance, Developer happiness, Interruptions impact, Code review quality, Technical debt waste
- **Métricas propostas**: Comprehensive multi-dimensional framework including: productivity dimensions (velocity, quality, satisfaction), technical factors (product, process, environment), soft factors (culture, individual skills, team dynamics, work environment, project characteristics), four lenses perspective (individual, team, organization, market), knowledge work-based metrics (outcome-oriented, process-oriented, people-oriented, multi-oriented techniques)
