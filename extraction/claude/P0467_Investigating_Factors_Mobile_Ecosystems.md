## Objetivo

Identificar fatores que influenciam a Developer Experience (DX) em mobile software ecosystems (MSECO), usando o framework de Fagerholm & Münch como base teorica.

---

## Questoes de Pesquisa

- **RQ1**: Quais sao os fatores chave que influenciam a developer experience no contexto de ecossistemas de software mobile?
- **RQ2**: Como podem esses fatores ser categorizados dentro das tres dimensoes de DX (Development Infrastructure, Feelings About Work, Value of Own Contribution)?
- **RQ3**: Como a DX em MSECO difere de contextos de desenvolvimento de software tradicional?

---

## Framework Utilizado: Fagerholm & Münch DX (2012)

3 dimensoes de DX aplicadas ao contexto MSECO:

### Development Infrastructure
- Tools quality and availability
- Documentation completeness
- SDK quality and stability
- API availability and design
- IDE support and integration
- Platform compatibility
- Testing infrastructure

### Feelings About Work
- Community engagement
- Developer satisfaction
- Motivation and autonomy
- Sense of belonging to ecosystem
- Peer recognition
- Support from platform owner

### Value of Own Contribution
- Market reach potential
- App store visibility
- Revenue opportunities
- User base access
- Brand association
- Recognition from ecosystem

## Metricas e Instrumentos de Avaliacao

### Framework de Classificacao: Fagerholm & Münch DX (2012)

**3 Dimensoes principais de DX em MSECO:**

#### 1. Development Infrastructure
Fatores tecnico-infrastruturais:
- Tools quality and availability
- Documentation completeness
- SDK quality and stability
- API design and availability
- IDE support for mobile development
- Platform compatibility across devices
- Testing infrastructure and tools

#### 2. Feelings About Work
Fatores psico-sociais e motivacionais:
- Community engagement (forum, support)
- Developer satisfaction with platform
- Motivation and autonomy
- Sense of belonging to ecosystem
- Peer recognition mechanisms
- Support from platform owner (Apple, Google, Microsoft)

#### 3. Value of Own Contribution
Fatores economicos e reconhecimento:
- Market reach potential (user base size)
- App store visibility and discoverability
- Revenue opportunities (monetization models)
- User base access (adoption potential)
- Brand association with platform
- Recognition within ecosystem

### Fatores Identificados (20 total)

**Resultado principal:** 20 fatores de influencia de DX extraidos de 11 estudos

Exemplos (nao lista completa):
- Lag in response to API/SDK changes
- Unclear SDK documentation
- Difficulty in app store ranking
- Platform stability and reliability
- Community support quality
- Revenue sharing models clarity

### Metodo de Analise

**Thematic Analysis com 6 passos:**
1. Leitura repetida dos textos
2. Geracao de codigos iniciais
3. Combinacao de codigos em temas
4. Desenvolvimento de temas maiores
5. Definicao clara de cada tema
6. Finalizacao da analise tematica

**Rigor metodologico:**
- Member checking com co-autores
- Consenso entre pesquisadores para resolucao de desacordos
- Rastreabilidade entre citacoes e fatores identificados

### Confiabilidade e Validacao

**Limitacoes:**
- Nenhuma validacao quantitativa com desenvolvedores
- Analise tematica puramente qualitativa
- Sem inter-rater reliability measures (Cohen's kappa)
- Sem triangulacao com dados empiricos

**Possibilidades futuras de validacao:**
- Survey com desenvolvedores mobile para validar importancia dos 20 fatores
- Estudo empirico correlacionando fatores com satisfacao/produtividade
- Analise de dados de app stores para validar economic factors
