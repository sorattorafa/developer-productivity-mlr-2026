## Objetivo

Investigar, com base no framework Developer Experience (DevEx), como ferramentas de AI-assisted coding (GitHub Copilot e Windsurf) afetam a produtividade, a cognitive load e os fluxos de trabalho das equipes em uma fintech brasileira, comparando praticas de desenvolvimento antes e depois da adocao e indo alem de metricas de adocao/uso para indicadores de nivel de sistema (delivery e reliability).

---

## Questoes de Pesquisa

- RQ1: How do AI-assisted coding tools affect feedback loops (e.g., CI/CD pipelines, code review cycles, and access to technical information)?
- RQ2: How do AI-assisted coding tools affect cognitive load (e.g., code comprehension, AI-generated code validation, prompt formulation, and incident resolution)?
- RQ3: How do AI-assisted coding tools affect flow state (e.g., developer-reported experience, task focus, and learning)?

## Fatores que Influenciam Produtividade

### Fatores Positivos
| Fator | Categoria |
|-------|-----------|
| AI-assisted coding em trabalho planejado/estruturado (Bitbucket: review time −53.1%, merge time −40.3%, pipeline frequency +185.8%) | Technical / Process |
| Acesso rapido a informacao tecnica e compreensao de codigo desconhecido via IA | Technical |
| Mudancas menores, incrementais e focadas em features (mais commits de Feature, menor churn) | Process |
| Melhor organizacao de tarefas, aprendizado acelerado e suporte a implementacao (flow) | Human |

### Fatores Negativos
| Fator | Categoria |
|-------|-----------|
| Trabalho reativo/incident-driven (GitLab: review time +123%, merge time +133.3%, pipeline duration +79.0%, pipeline frequency −33.7%) | Process |

## Resultados Principais

- Adocao: 29 de 33 desenvolvedores com acesso ao Copilot, 28 usaram ao menos uma vez (96.6% dos licenciados); 37,692 code completions e 17,729 chat interactions; ~17–20 usuarios ativos por semana; pico em agosto; dois desenvolvedores testaram Windsurf.
- Uso predominantemente para implementacao (sugestoes de codigo) e menos conversacional.
- RQ1 (Tabela 1, Q3-2024 vs. Q3-2025): GitLab — pipeline frequency ↓33.7%, duration ↑79.0%, success rate −7.9 pp, PR creation ↓22.6%, median review time ↑123%, median merge time ↑133.3%; Bitbucket — pipeline frequency ↑185.8%, duration ↑2.7%, success rate −16.9 pp, PR creation ↑16.0%, review time ↓53.1%, merge time ↓40.3%.
- Padrao dependente do fluxo de trabalho: Bitbucket (features planejadas) mais rapido; GitLab (manutencao/incidentes, associados via Jira) com ciclos mais longos; ganhos de throughput nao se traduziram em entrega mais estavel.
- RQ2: maior proporcao de commits de Feature, maior commit frequency e menor code churn normalizado por contribuicao; acceptance rate de 30.2% por contagem e 21.9% por linhas de codigo; incident tickets −35.2%, mas mediana de resolucao +377%.
- RQ3 (evidencia qualitativa do estudo anterior, n=9): experiencias positivas de flow (organizacao, aprendizado, implementacao), mas necessidade de orientar, revisar e validar o codigo gerado.
- Conclusao: AI adoption como transformacao sociotecnica; focar apenas em adocao ou uso e insuficiente para avaliar o valor criado.

---

## Desafios do Uso das Metricas

- Medir o impacto organizacional real de AI coding assistants continua dificil; metricas de adocao e uso sozinhas nao capturam efeitos no workflow, DevEx e delivery performance.
- Pesquisas anteriores dependem de experimentos controlados, estudos de curto prazo ou self-reported satisfaction; poucos analisam indicadores de sistema de longo prazo (deployment frequency, incident resolution time, code review throughput).
- Ganhos individuais de eficiencia nao se traduzem prontamente em melhorias de nivel de sistema.
- Comparacao entre trimestres diferentes sujeita a confounders (composicao da equipe, maturidade dos repositorios, mix de projetos, mudancas de processo, pressoes operacionais).
- Rapida evolucao do ecossistema de ferramentas (Windsurf lancado e descontinuado em poucos meses) exige pesquisa longitudinal.
- Acceptance rate difere conforme a unidade (contagem vs. linhas de codigo).

## Limitacoes

- Comparacao entre trimestres e contextos organizacionais diferentes; composicao da equipe, maturidade dos repositorios, mix de projetos, mudancas de processo e pressoes operacionais podem ter influenciado as variacoes; alegacoes causais devem ser tratadas com cautela.
- Estudo de caso em uma unica fintech; nao generalizavel (cultura, praticas, contexto regulatorio e estrategias de adocao diferem).
- Fase qualitativa (retrospectivas e entrevistas) ainda incompleta; evidencia qualitativa atual vem do estudo anterior.
- Telemetria do Copilot apenas "when available"; Windsurf apenas por registros organizacionais.

---

## Contribuicao Principal

O estudo oferece evidencia longitudinal, em ambiente de producao de uma fintech brasileira, de que o impacto de AI-assisted coding tools e fortemente dependente do contexto: acelera trabalho estruturado e rotineiro, mas aumenta friccao e custos de coordenacao em trabalho reativo e orientado a incidentes, caracterizando um "productivity paradox" alinhado a amplification hypothesis. Usando o framework DevEx, mostra que a cognitive load e deslocada para supervisao e validacao e recomenda avaliar a adocao de IA com metricas de delivery e reliability, e nao apenas metricas de uso.
