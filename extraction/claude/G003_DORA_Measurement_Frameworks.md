## Objetivo

Orientar organizações na seleção apropriada de frameworks de medição para medir desenvolvimento de software, considerando diferentes objetivos organizacionais (experiência do desenvolvedor, excelência do produto, efetividade organizacional) e os tipos de dados coletáveis.

---

## Frameworks e Metricas

### Frameworks Mencionados
- DORA Software Delivery Metrics
- SPACE Framework
- DevEx Framework
- H.E.A.R.T Framework

### Metricas Propostas/Discutidas
- **Dados auto-relatados:** Surveys, Interviews, Focus groups, Diary studies
- **Dados baseados em logs:** Quantity metrics, Time-based metrics, Frequency metrics
- **Métricas de produtividade:** Code commits, Pull requests
- **Métricas de bem-estar:** Developer well-being, Satisfaction, Perceived effectiveness

---

## Principais Contribuicoes

- **Taxonomia de frameworks:** Categoriza frameworks de medição em três focos principais: experiência do desenvolvedor, excelência do produto, e efetividade organizacional
- **Dualidade de dados:** Distingue entre dados auto-relatados (para capturar experiências subjetivas) e dados baseados em logs (para escalabilidade e consistência)
- **Estratégia de seleção:** Propõe um processo de 2 passos: (1) decidir o "por quê" (objetivos organizacionais) e (2) decidir o "o quê e como" (métricas e coleta de dados)
- **Sobreposição de métricas:** Reconhece que frameworks diferentes podem medir as mesmas métricas mas com propósitos distintos
- **Adaptação para IA:** Fornece orientação específica sobre como adaptar frameworks existentes para medir impacto de ferramentas assistidas por IA sem descartar estratégias anteriores

---

## Contribuicao Principal

Este documento estabelece uma metodologia rigorosa para seleção de frameworks de medição em desenvolvimento de software, reconhecendo que não há "um framework para todos os casos". A contribuição principal é fornecer um modelo de decisão estruturado baseado em objetivos organizacionais, diferenciando tipos de dados coletáveis, e demonstrando como combinar frameworks complementares (ex: DORA + H.E.A.R.T) para compreender impacto holístico de mudanças tecnológicas como IA no desenvolvimento de software.
