# A Multi-Faceted Approach to Measuring Engineering Productivity

## Dados Bibliográficos
- **Autores**: Manish Sanwal, Ishan Deva
- **Ano**: 2024
- **Venue**: International Journal of Trend in Scientific Research and Development (IJTSRD)
- **DOI**: IJTSRD69393
- **Fonte**: Google Scholar
- **Paper ID**: P1272

## Objetivo
Este artigo apresenta um framework abrangente para medir produtividade de desenvolvimento através de uma calculadora de produtividade que integra múltiplas métricas de Agile, qualidade de código, atividades de revisão, esforços de QA e implantação. O estudo foi validado com 7 times em 7 sprints, demonstrando correlações entre métricas e mudanças de práticas. O framework é projetado como ferramenta de autoavaliação para melhorias contínuas, não para comparação entre times.

## Métricas e Instrumentos de Avaliação
- **Frameworks mencionados**: Agile, DORA metrics
- **Métricas mencionadas**: Story Points Completed, Blocked Tickets, Spikes Executed, Cycle Time, Number of Commits, PRs Opened, Code Coverage, Unit Test Quality, Security Vulnerabilities, PR Reviews, PR Comments, PRs Merged, Deployment Frequency, Lead Time for Changes, Change Failure Rate, MTTR
- **Métricas propostas**: Multi-faceted productivity calculator with weighted metrics across 6 categories: Agile Practices, Code Contributions, Code Quality, Review Activities, QA Efforts, Deployment Metrics. Normalization factor based on team size
