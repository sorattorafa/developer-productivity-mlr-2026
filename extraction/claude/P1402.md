# Identifying the Factors That Influence Trust in AI Code Completion

## Dados Bibliográficos
- **Autores**: Adam Brown, Sarah D'Angelo, Ambar Murillo, Ciera Jaspan, Collin Green (Google LLC)
- **Ano**: 2024
- **Venue**: AIware 2024 - ACM International Conference on AI-Powered Software
- **DOI**: 10.1145/3664646.3664757
- **Fonte**: Google Scholar
- **Paper ID**: P1402

## Objetivo
Este artigo investiga fatores que influenciam confiança de desenvolvedores em ferramentas de conclusão de código com IA através de entrevistas e análise de logs de 1M sugestões. Identifica três categorias de fatores: características da sugestão, características do desenvolvedor e contexto de desenvolvimento. Propõe uso de acceptance rate como proxy para confiança e análise de regressão logística para medir importância relativa.

## Dados da Pesquisa
- **Tipo de Estudo**: Empirical Study with Mixed Methods
- **Método**: Mixed Methods (Interviews + Logs-based Analysis)
- **Amostra**: N=12 interviewed developers + 1M code completion suggestions analyzed
- **Contexto**: Industry (Google)

## Métricas e Instrumentos de Avaliação
- **Frameworks mencionados**: Trust framework for AI-powered tools
- **Métricas mencionadas**: Acceptance rate of suggestions, Code completion quality score, Suggestion length, Character position in line, Model quality score, Readability in suggestion language, Prior code changes, Developer expertise (language proficiency, familiarity), Job level, Work demographics, Bug density, Test file patterns, Change scope
- **Métricas propostas**: Framework identifying three factors influencing developer trust in AI code completion: (1) Characteristics of the suggestion (quality, length, correctness); (2) Developer characteristics (expertise, familiarity, experience); (3) Development context (work type, project complexity, sensitive tasks). Proposes logs-based measurement of acceptance rates and correlation analysis with feature importance
